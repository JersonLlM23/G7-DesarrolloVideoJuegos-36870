## Subtema

**Tema 1: Input Map y acciones**

Estudio y aplicación del sistema Input Map de Godot, incluyendo la creación de acciones personalizadas, asignación de dispositivos de entrada y configuración de la zona muerta (Deadzone).

## Versión del motor

- **Godot Engine:** 4.7.2
- **Lenguaje de programación:** GDScript

## Estructura del proyecto

- `proyecto/`: proyecto práctico desarrollado en Godot.
- `presentacion/`: diapositivas de la clase magistral en formato PDF.
- `reto/`: enunciado y solución del reto propuesto.
- `plan_clase/`: planificación de la clase magistral.
- `README.md`: información general del trabajo e instrucciones de ejecución.

## Cómo ejecutar el ejercicio

1. Descargar o clonar este repositorio.
2. Abrir Godot Engine 4.7.2.
3. Seleccionar la opción **Importar**.
4. Buscar y seleccionar el archivo `project.godot` ubicado en la carpeta del proyecto.
5. Esperar a que Godot importe los recursos.
6. Ejecutar el proyecto mediante el botón **Ejecutar proyecto (F6/F5)**, según corresponda.

## Descripción

El ejercicio práctico demuestra el funcionamiento del sistema Input Map mediante un personaje controlado por cuatro acciones personalizadas. Estas acciones permiten gestionar el movimiento sin depender directamente de las teclas físicas dentro del código.
